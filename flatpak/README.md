# Retired Hexenwail desktop packaging

This directory is inherited from the Hexenwail desktop codebase and is retained only as historical source material. Its manifests target the former SDL/OpenGL application and no longer build the current engine.

YouHexen2 is an Emscripten-only HTML5/WebAssembly port distributed as an installed iOS PWA. See the [project README](../README.md), [build guide](../docs/COMPILE), and [PWA guide](../docs/PWA.md) for current instructions.

The `io.github.hexenwail.hexenwail` application ID and Hexenwail product strings inside these retired manifests describe the old desktop package; they are not the YouHexen2 brand.
